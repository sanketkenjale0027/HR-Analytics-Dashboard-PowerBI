# 📊 HR Analytics Dashboard – Power BI

## 📌 Project Overview
The HR Analytics Dashboard is an interactive Power BI project designed to analyze employee data, workforce distribution, training performance, and organizational insights. It helps users monitor key HR metrics and understand employee trends through dynamic visualizations and interactive filters.

## 🎯 Project Objectives
- Analyze total and active employees.
- Monitor employee status, including active and terminated employees.
- Analyze workforce distribution across different zones and departments.
- Evaluate training costs and training outcomes.
- Understand employee demographics and performance.
- Identify trends in employee roles, divisions, and employment types.

## 🛠️ Tools & Technologies
- Microsoft Power BI
- Data Visualization
- Data Analysis
- DAX Measures
- Interactive Slicers and Filters
- Charts, KPIs, and Decomposition Tree

## 📊 Key Features
- **Interactive Year Filter:** Analyze HR data for 2022 and 2023.
- **State Filter:** Filter and explore data across approximately 14 states.
- **Employee Overview:** Track total employees, active employees, and average employee age.
- **Training Analysis:** Examine training costs, training outcomes, and training program categories.
- **Workforce Analysis:** Explore employee distribution by zone, department, division, role, and employment status.
- **Employee Demographics:** Analyze gender, race, marital status, and other workforce characteristics.
- **Performance Analysis:** Review employee performance categories and identify areas for improvement.
- **Multiple Dashboard Pages:** Navigate between Home Page, Training, Zone Information, Employee, and Employee Information.
